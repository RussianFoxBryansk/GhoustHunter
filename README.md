🏚️ Система процедурной генерации

В основе лежит классический алгоритм клеточных автоматов:

Начальная сетка заполняется случайным шумом с заданным процентом заполнения

Несколько итераций клеточных правил превращают хаос в узнаваемые комнаты

Автоматическое заполнение внутренних «дыр» для целостности стен

Удаление изолированных кластеров и принудительное соединение оставшихся

Генерация повторяет попытку до достижения нужного количества комнат

В случае неудачи создаётся минимальный крестообразный лабиринт

Каждая комната получает информацию о соседях (стены сверху/снизу/слева/справа), что позволяет правильно настраивать видимые проходы и стены. Для разнообразия поддерживаются альтернативные классы комнат, выбираемые на основе псевдослучайного хеша от координат и сида.
